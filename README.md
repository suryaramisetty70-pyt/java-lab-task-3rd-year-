## 🚀 How to Run the Code

1. Navigate to the desired folder:
   ```powershell
   cd Week1
   ```

2. Compile and Run any task file:
   ```powershell
   javac Week1_Task1_ArrayIndexAccess.java
   java Week1_Task1_ArrayIndexAccess
   ```
